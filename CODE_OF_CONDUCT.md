# Code of Conduct

Ruckus contributors must provide a respectful, harassment-free environment regardless
of identity, background, experience, disability, or role. Be constructive, protect
private user and report data, avoid sexualized or threatening conduct, and do not use
project access to target campus communities.

Project maintainers may edit, reject, or remove contributions and participation that
violate these expectations. Report conduct concerns privately through the repository
owner’s GitHub security/contact channel; do not post sensitive evidence in a public
issue. A permanent project conduct address remains an owner release gate.

Enforcement should be proportionate, documented, and free from retaliation. Immediate
danger belongs with local emergency services, not a repository issue.
