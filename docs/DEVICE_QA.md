# Physical-device QA

This checklist is intentionally **not satisfied by automated exports or simulators**.
Record device/OS/build/date/evidence for each result.

- [ ] Fresh install, sign-up, email verification callback, age/safety, onboarding
- [ ] Sign-in, password recovery, session persistence, sign-out
- [ ] Light/dark, large text, screen reader, reduced motion, keyboard, rotation policy
- [ ] Discover swipe and accessible buttons; confirmed/pending/waitlist outcomes
- [ ] Capacity contention against a connected hosted test backend
- [ ] My Events, cancellation/promotion, public share/referral links, calendar permission
- [ ] Private chat reconnect, pagination, retry, reply/reaction/copy/report, block effect
- [ ] Organizer create/manage/announcement/cancel/archive and organization roles
- [ ] Host QR rotation; attendee camera permission/check-in/replay/expiry
- [ ] Contextual push education, allow/deny, foreground/background/deep-link behavior,
      preference filtering, token refresh/invalidation, privacy-safe preview
- [ ] Offline/reconnect, low-memory/background resume, slow network, API error recovery
- [ ] Account export request and deletion request/immediate sign-out/pending screen
- [ ] Public web event/org/referral/support/legal/deletion/partnership pages

Store submission, production email/push, legal copy, support channels, campus safety
escalation, and deletion URL must remain blocked until owner evidence exists.
